## Overview

This policy change is part of a broader effort to simplify and streamline the copilot code review billing process for organizations with members who have a Copilot license. As of December 30, 2026, if you haven't chosen how to bill Copilot code review for members with a Copilot license, those reviews will be billed to your organization. This change aims to ensure consistency and accuracy in billing, which can help reduce administrative burdens and improve the overall copilot experience for all users. By defaulting to billing to the organization, this policy change may impact the copilot license costs for some users, although the exact impact will depend on the specific use cases and billing configurations.
